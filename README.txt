1. На github.com создай новый репозиторий (Public или Private).
2. Нажми "uploading an existing file" и перетащи ВСЕ файлы из этой папки
   (включая папки www и .github). Нажми Commit.
3. Открой вкладку Actions. Сборка запустится сама (3-5 минут).
4. Когда будет зелёная галочка, открой сборку, внизу в Artifacts скачай gym-diary-apk.
5. Распакуй zip, перекинь app-debug.apk на телефон и установи
   (разреши установку из неизвестных источников).
